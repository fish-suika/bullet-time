# BULLET TIME — Phase 1（最小プロトタイプ）設計

本人の「ゲーム制作設定資料（仮タイトル BULLET TIME）」の §17 プロトタイプ 8 項目を、STAGE 1 の 1 ステージで満たす。
確認したいのは「銃弾を操作する → 対象を選ぶ → 物体が連鎖する → 未来が変わる」が面白いか、だけ。

## 決まっていること（2026-10-06 本人回答）

- 操作は **分岐点で方向（狙う対象）を選ぶ** 方式。弾は自動で飛び、分岐点で時間が止まって選ぶ。飛行中に細かく曲げさせない
- **PC とスマホ両方**。キーボードとタップ
- 作り方は爆弾バレーと同じ: three.js r128（cdnjs）＋ `src/` を `build.sh` で 1 枚の HTML に結合、`verify.html` で検証
- 物理は「倒れる・転がる・落ちる・吹き飛ぶ」を本物の剛体で見せたいので **cannon.js 0.6.2（cdnjs、UMD、グローバル `CANNON`）** を使う

## STAGE 1「単純な未来」

目的: **主人公を助ける**（3.5 秒後に敵 A が主人公を撃つ。それまでに未来を変える）

### 配置（薄暗い倉庫・夜）

- 主人公: 部屋の奥の壁際、椅子に縛られて座っている
- 敵 A: 主人公の正面 3m で拳銃を構えている
- 敵 B: 部屋の右奥、木箱の横で見張り。拳銃を持つ
- 吊りランプ: 敵 A の真上、天井から鎖で吊るされている（鎖を撃つと落ちる）
- テーブル: 手前左。上に **バナナ** と ワイン瓶
- ガスボンベ（赤）: 敵 B の近く
- 窓: 手前の壁。プレイヤー（銃弾）は窓の外の狙撃銃から撃たれ、窓ガラスを割って入ってくる

### 撃てる対象と未来（物理で起きる。結果はアニメ固定にしない）

| 対象 | 連鎖 | 結果 |
|---|---|---|
| 敵 A | 敵 A が倒れる → 物音で敵 B が振り向き主人公を撃つ | GAME OVER（資料パターン A） |
| ランプの鎖 | ランプ落下 → 敵 A の目の前で砕ける → 敵 A が驚いて銃撃が天井へ外れる → 敵 B は物陰に伏せる | CLEAR「正攻法」（パターン B） |
| バナナ | バナナが飛ぶ → 敵 B の足元へ → 駆け寄った敵 B が踏んで転ぶ → 銃が暴発 → ガスボンベに命中 → 爆発 → 敵 A・B・木箱が吹き飛ぶ → 主人公は椅子ごと倒れて爆風の下をくぐり無傷 | CLEAR「バカな方法」（パターン C） |
| ワイン瓶 | 瓶が割れるだけ。誰も気にしない | GAME OVER（ハズレ。「何も変わらなかった」） |

- 敵 B が「駆け寄る」きっかけは、バナナが床に落ちた音。敵 A は撃つのをやめない → でも敵 B の暴発→爆発が 3.5 秒より前に起き、敵 A ごと吹き飛ぶ
- 成功判定は「主人公に弾が当たらず、主人公が爆発半径の致死範囲にいないまま、終了時刻（命中から約 6 秒）を迎えた」こと。結果はイベントの台本ではなく、敵の弾（レイキャスト）と爆発の判定から決まるようにする
- 物理のばらつきで偶然違う結果になってもよい（資料 §7「偶然成功する方法」）。ただし正攻法 2 つはほぼ確実に成功するよう調整する

## ゲームの流れ

1. **状況を見る**（約 2.5 秒、どのキー/タップでも飛ばせる）: 部屋をゆっくり見回すカメラ。上に目的「主人公を助けろ」
2. **発射**: 窓の外の銃口から発射。ガラスが割れ、弾は部屋の中央へ向かってスロー（0.08 倍速）で飛ぶ。カメラは弾の斜め後ろから追う
3. **分岐点**: 部屋の中央で時間が止まる（弾の周りの空気の揺らぎ・色が冷える演出）。撃てる対象 4 つに印（輪）が出て、今選んでいる対象から弾まで点線の予測線が出る
   - PC: ←→↑↓ で画面上の方向にある次の対象へ選択を移す、Enter / Space で「撃つ」
   - スマホ: 印を直接タップで選択、もう一度タップ（または「撃つ」ボタン）で確定
   - 表示は「狙う」「変更」程度だけ（資料 §13）
4. **命中まで**: 選んだ対象へ曲がって飛ぶ。近づいたら更にスロー＋カメラが寄る＋風切り音
5. **命中**: 時間を通常速度に戻し、剛体に衝撃を与えて連鎖を起こす。カメラは部屋全体の引き画へ
6. **結果**: 連鎖が終わったら「CLEAR」/「GAME OVER」と、今回起きた連鎖を矢印つきの短い行で出す（例: ランプ → 落下 → 敵が驚く → 銃撃が外れる → 主人公 生存）。見つけた未来の数「未来 2/4」
7. **リトライ**: R キー / 画面のボタン / 結果画面のタップで、0.3 秒以内に分岐点の直前（発射直後）からやり直す。最初からやり直す「状況を見る」は 2 回目以降飛ばす

## 改訂：STAGE 1 の 4 つの未来を入れ替え（2026-10-06 本人承認）

上の「撃てる対象と未来」の表（ランプ・バナナ・ワイン瓶）は **この節に置き換える**。倉庫・主人公（椅子に縛られている）・敵 A（主人公を狙い、約 3.5 秒後に撃つ）・敵 B（懐中電灯を持って窓を見張る）・縦 9:16 の画面・分岐点の流れ・結果画面・「未来 n/4」・リトライはそのまま。吊りランプは部屋の明かりとして残る（撃てない）。
求めるもの：**連鎖を長く、バカバカしく、予想を裏切る**。結果はアニメの台本ではなく、剛体の衝突・敵の弾（レイキャスト）・単純な状態機械から決まる（狙いの補正などの「そっと押す」仕掛けは使ってよい）。

| 対象 | 見た目 | 結果 |
|---|---|---|
| ① 敵 A | 普通の答え | GAME OVER（ふつう）／ときどき「CLEAR？ 奇跡的に全部外れた」 |
| ② 消火器 | 地味な置物（床に寝ている） | CLEAR（長い連鎖） |
| ③ ゴムのアヒル | 左奥の棚の上のどうでもいい物 | CLEAR（予想を裏切る） |
| ④ ガスボンベ | いかにも正解 | GAME OVER（爆発しない） |

### ① 敵 A（結果画面の連鎖ログ）
敵A → 倒れる → 銃が床を滑って敵Bの足元へ → 敵Bがかがんで拾おうとする → 敵Bのお尻が棚に当たり棚が揺れる → ペンキ缶が敵Bの頭にすっぽりかぶさる → 前が見えない敵Bがめちゃくちゃに撃つ → 1発が主人公に命中。
- A が倒れると銃が手を離れて B の足元へ滑る（床に落ちた音を B が聞く）。B は銃のほうへ歩いてかがむ。
- かがんだお尻が棚に当たる（棚はこの時だけ揺れる）と、棚の上のペンキ缶が B の頭の位置へ飛んでかぶさる（落ち先は頭の大きさの中でばらつく）。
- 缶をかぶった B は、向きをめちゃくちゃに変えながら 7 発撃つ（主人公の方向を中心に ±0.55rad のばらつき）。レイキャストで主人公に当たれば GAME OVER。
- 全部外れれば CLEAR。タイトルは「CLEAR？」、サブは「奇跡的に全部外れた」、結果画面に「隠れた未来を発見」の印を付ける。**GAME OVER が約 15/20**（偶然の成功が約 25%）になるよう調整する。

### ② 消火器
消火器 → 噴射して床を滑走 → ドラム缶を弾く → 転がるドラム缶が敵Bをなぎ倒す → 懐中電灯が宙を舞い敵Aの顔を照らす → まぶしくてAの弾が外れる → 外れた弾がスプリンクラーに当たる → 倉庫中が水浸し → 起き上がろうとした敵が次々すべって転ぶ → 主人公 生存。
- 消火器は推力を持つ剛体。白い噴射の粒を出して滑り、ドラム缶に当たる。ドラム缶は転がって B をなぎ倒す。
- B の懐中電灯は手を離れて A の顔の前へ飛び、光が A の顔を向く。A は反射で、見えないまま天井のスプリンクラー（外れ弾の先）を撃つ。
- スプリンクラーに当たると水が降り、床が濡れて光る。倒れた敵が起き上がり（立ち上がるポーズ）、すべって転ぶのをくり返す。A はもう主人公を撃たない。
- **ほぼ 20/20 で CLEAR**。

### ③ ゴムのアヒル
ゴムのアヒル → ピーッと鳴いて棚から落ちる → 敵Aが「誰だ！」とBに振り向く → Bも驚いてAを照らす → 撃ち合い → 2人とも倒れる → 敵が勝手に全滅 → 主人公 生存。
- アヒルの鳴き声（WebAudio）を A と B が聞く。A は B が鳴らしたと思って振り向き（吹き出し「誰だ！」）、B も A を照らして向き直る。
- 2 人は同時に撃ち合い、互いに当てて倒れる。A が振り向いたので、主人公は撃たれない。
- **ほぼ 20/20 で CLEAR**。

### ④ ガスボンベ
ガスボンベ → 栓が飛ぶ → ロケットになって跳ね回る → 敵2人は伏せてよける → 主人公に直撃。
- 爆発しない。栓が飛び、ボンベは速さの向きに噴射する剛体（ほぼ無重力・壁や天井で高く跳ね返る）になって倉庫を跳ね回る。ガスの噴射の粒を出す。
- ロケットが近づくと敵 2 人は伏せる（その間は当たらない）。途中から速さの向きを主人公の胸のほうへ寄せ、主人公の体（胸の高さ）に当たる（衝突）と、主人公は椅子ごと倒れる。
- **ほぼ 20/20 で GAME OVER**。サブは「いちばん派手な方法で失敗」。

### 配置の考え方（縦 9:16・375x812 の分岐点で 4 つの印が重ならない）
撃てる 4 つの物は、床の前（消火器）・中央（敵 A）・右前（ガスボンベ）・左奥の棚（アヒル）に散らす。ドラム缶（消火器と B を結ぶ線上）と、B の後ろの棚（上にペンキ缶）は撃てない仕掛け。スプリンクラーは A から見て主人公の頭上の天井。

### 検証
`verify.html` で 4 つの結果と連鎖ログをそれぞれ確認し、配置と乱数を揺らした 20 回ずつの成功数（① は CLEAR になった数・失敗数、④ は失敗数）を表示する。
